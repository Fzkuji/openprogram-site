# openprogram-site

Published build of [openprogram.io](https://openprogram.io) — the OpenProgram
documentation site.

Everything here is generated. The sources live in
[Fzkuji/OpenProgram](https://github.com/Fzkuji/OpenProgram) under `docs/`, and
a workflow in that repository rebuilds and pushes this branch whenever the
documentation changes. Edit the docs there; edits made here are overwritten by
the next publish.
